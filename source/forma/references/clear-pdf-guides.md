# Clear PDF guides: cards, comparisons and short copy

Use this optional reference for a requested clean, easy-to-scan PDF guide. Brand owns the document composition; Foundations owns hierarchy and spacing. This is a reusable pattern, not Forma's compulsory identity or a rule for every report.

## Origin and scope

A nine-page academic concept guide was generated with ReportLab and visually inspected in October 2026. The user specifically approved the encounter cards, alternating table rows and understandable copy, then requested reuse. The original content, private repository references and personal paths are not distributed. The [neutral print specimen](../assets/clear-pdf-guide.html) reproduces the two approved structural patterns with original generic copy. It is HTML authoring material, not a pre-exported or tagged PDF.

## Choose a shape that matches the information

| Content | Composition | Reading order |
|---|---|---|
| Situation with available actions | Soft-background card with a narrow accent rail | Title and category, situation, explicit choice line |
| Named concepts and their meanings | Two-column table with a dark header and alternating light rows | Concept, explanation on the same row |
| Procedure | Numbered steps | Action, concrete deliverable, completion condition |
| Proposed scope | Distinct labeled groups | First delivery, later work, unresolved decisions |

Keep the situation and choices in one card. A category aligns with its title but wraps below it when necessary. Use real table headers; keep row labels visually stronger than their descriptions. Never separate a condition from the outcome it qualifies to make a page look cleaner.

## Starting values, not universal tokens

The approved guide used A4 portrait, roughly 17 mm side margins, sans-serif body text around 11.5-12 pt, 1.35 line spacing, 16 pt card titles and 29 pt page titles. Cards used about 16 pt internal spacing and a 4 pt accent rail. These values are a starting profile; measure the actual font and content before exporting.

Optional palette: navy `#132338` for headings, teal `#086D73` for emphasis, body `#24364A`, muted text `#526476`, card background `#F0F4F5`, and alternating rows `#EAF3F3` / `#F5F6F6`. Keep approved consumer branding when it differs. Color supports labels and hierarchy; it must not be the only indicator of status. Do not redistribute system fonts: use available permitted fonts and inspect fallback metrics.

## Copy contract

Lead with what the reader needs to understand or do. Replace dense paragraphs with a situation and an explicit choice only when that structure fits the meaning. Use short, concrete sentences and informative titles. Preserve every required condition, number, source, uncertainty and relationship. Simplifying language does not authorize inventing rules, deleting caveats or presenting proposals as implemented facts.

The guide's thematic language is not part of this pattern. Adapt copy to the destination language. This contract is self-contained and does not require an external writing plugin.

## Export and verification

1. Inventory required content before restructuring. Map it to sections and pages.
2. Use content-driven heights. Do not freeze card heights from a short example, shrink body text to hide overflow or truncate long names.
3. Print or render through an available tool. A specimen HTML file does not complete a PDF request. Set A4 and check margins, font loading, breaks and repeated headers; a card longer than a page needs deliberate splitting rather than clipping.
4. Open the exported PDF. Inspect every page and full-size examples of cards and tables; verify extracted text, page order, accented characters and links separately.
5. Report only executed checks. Readability approval and visual inspection do not prove tagged PDF accessibility, screen-reader order, PDF/UA conformance or printer color accuracy.

For general export obligations, follow [artifact workflows](artifact-workflows.md). For exact reproduction, preserve the approved profile and verify the actual render; for inspiration, adapt values while preserving the reading relationships.
