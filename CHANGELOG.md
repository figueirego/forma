# Histórico

## 1.23.0 — distribuições para outros assistentes

- Plugin para Claude Code com catálogo próprio e invocações `/forma:forma`, preservando o plugin do Codex.
- Agent Skills em 12 pastas irmãs para instalação em Cursor, Copilot, OpenCode, Gemini CLI e outros hosts compatíveis.
- Instalador local com simulação por padrão, comparação de conteúdo e recusa de sobrescrita; sem rede ou alteração das configurações do assistente.
- Links relativos rebaseados, recursos executáveis idênticos entre distribuições e testes de instalação em caminho independente.
- Matriz de compatibilidade com fontes oficiais e distinção entre validação do pacote, descoberta e execução de uma tarefa de design.

## 1.22.1 — edição comunitária

- Fonte e distribuição reproduzível no mesmo repositório, com catálogo `forma-community`.
- Licença MIT, instruções de contribuição, revisão por CODEOWNERS e validação em pull requests.
- Remoção de caminhos pessoais, perfil de projeto privado e blocos literais de CSS de terceiros.
- Preservação dos componentes executáveis da Forma 1.22.0; nenhuma alteração de comportamento visual nesta publicação.

Esta edição mantém uma coordenadora e 11 especialistas. Testes e auditorias anteriores permanecem identificados como históricos, não como certificação de todos os consumidores.
