## How the library contributes to a project

The coordinator selects a task and one primary specialist. Reference investigates a bounded set of relevant examples when needed. The findings inform one design direction, shared tokens and implementation decisions. Validation checks the resulting consumer and the scope of each claim.

Candidate counts describe catalog coverage. Observed claims describe bounded evidence. Neither establishes that every destination has been visited, that its current implementation is known, or that a new project already reproduces it.
