# Sources: use cases and incorporation criteria

Use this to choose references, review a skill or combine multiple sources. This table organizes materials examined since 2026-10-25, with revisions identified below; it is neither a quality ranking nor an instruction to install everything. Read only the method relevant to the task and check the current version before executing an integration.

The operational library uses Forma records. Historical sources are research evidence, not mandatory modules or renamed content. For new contributions, follow [authorship and incorporation](authorship.md).

## How to incorporate a source

1. Identify **type and authority**: normative standard, official documentation, code, skill, community catalog or style example.
2. Record version/commit/hash, consulted files, license and limitations. Distinguish documented, statically demonstrated, observed during execution and inferred.
3. Extract a **use case**, the principle that addresses it and the condition where it stops helping. Do not import a framework, package or additional approval merely because the source uses them.
4. Classify: **adopt**, **adapt**, **already covered**, **reject** or **pending evidence**. Connect each addition to the existing reference and an observable test.
5. Check conflicts and duplication. Multiple lists repeating the same origin are not independent evidence. Keep the original source and adaptation separate.

Minimum record: `source + identity -> capability/case -> evidence -> principle -> limits/license -> skill destination -> verification`.

## Skills and plugins: choose by the work

| Source | Use when | Transferable rule / limit |
|---|---|---|
| Impeccable | Refine, audit, extract or adapt an existing UI | Preserve versus redesign, context and rendered review; aesthetic absolutes are not standards |
| Design Motion Principles | Create/audit motion | Purpose, frequency, interruption, continuity and reduced alternative; do not guarantee GPU behavior from a CSS property |
| API Design | Convert technical contracts into experience states | Validation, conflict, pagination, authorization, retry and pending 202; preserve backend conventions |
| UI/UX Pro Max | Targeted lookup by domain/stack | Short query, checked relevance and source; result ranking does not determine WCAG level |
| ECC Research Ops + Design System | Investigate evidence and audit consistency | Separate facts/inference/recommendations; criterion/finding per dimension without certifying scores |
| Figma | Design source, tokens, components, reconciliation and handoff | Checked authority, IDs, bindings and variants; [integration](integrations.md) depends on the actual file and contract |
| Open Design | Generate/refine artifacts in the connected runtime | Stable mode, project, request and execution; polling does not regenerate; paid generation/authentication follow the contract |
| REA | Trace an existing reference | Complete source through direct inspection; binary/runtime when the question requires it; partial evidence remains partial |

## Quick routing

- **"Fix the centering"** -> current component/tokens + spatial contracts. Do not randomly choose styles or request external generation.
- **"I have not chosen the identity yet"** -> comparable directions; Huashu/Oil/catalogs as references, with a contextual decision.
- **"I want it like this reference"** -> capture + source/version + fidelity gates; an inspired catalog does not replace the reference.
- **"I want to adapt this technology to other projects"** -> mechanism, data, material, geometry, API and lifecycle; deliver a reusable example and cost by layer. Fixed appearance is not a portable component.
- **"I want an editable deck"** -> artifacts/export + brand; choose the pipeline by verified editability.
- **"Edit only this object"** -> target/revision + local patch + undo; preserve the rest and resolve obsolete results.
- **"Synchronize Figma and code"** -> authority and binding inventory; localized reconciliation without duplicating the library.
- **"Review everything"** -> matrix of areas and evidence; mark untested where runtime is missing. Do not turn complete reading into universal certification.

The new criteria are an original synthesis. Do not distribute repositories, lengthy texts, templates, fonts or assets with this skill. Consult [provenance](sources.md) and current integration contracts when actually using them.
